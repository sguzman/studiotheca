# Studiotheca ontology

The [catalog](catalog.json) indexes documented **studios** and their **experiments**. IDs are stable slugs. A studio's `concept` status means a documented creative direction, not a registered business or commercially cleared brand. Experiment statuses apply to specific treatments, not the entire studio.

Each `dossier`, `brand`, and `games` path is repository-relative and must resolve to an existing file. Original artwork and published gallery assets are indexed separately. A proposed source file in the media-import queue is not automatically available for viewing.
