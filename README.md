# Studiotheca

**Private creative archive for studios, visual identities, products, and games.**

This is not a source-code monorepo or a Taria/Projectarium replacement. It is a place to preserve creative intent, original materials, iterations, decisions, and ideas across multiple studios and prospective games.

- [Studios](studios/onyx-foundry/README.md) — start with **Onyx Foundry**
- [Onyx Foundry identity](studios/onyx-foundry/brand/README.md) — colors, typography, emblem, and current presentation
- [Brand experiments](studios/onyx-foundry/brand/experiments/README.md) — parallel visual directions with independent revisions
- [Game ideas](studios/onyx-foundry/games/README.md) — titles, premises, systems, themes, and production status
- [Types of games](explorations/game-types.md) — a studio-independent genre and format sandbox

- [Asset standard](docs/assets.md) — file names, sources, licenses, and presentation
- [Templates](templates/) — experiment and game-concept dossiers

## Working model

**Studio → identity → experiment → immutable versions → chosen presentation.**

Experiments coexist **in folders on `main`**, not on temporary Git branches. Any experiment can be resumed independently. Accepted work does not erase alternatives.

Creative concepts live here. Application and game source code belong in separate repositories and may be linked from the appropriate dossier.

Nothing is published or released merely because it has been recorded here.
