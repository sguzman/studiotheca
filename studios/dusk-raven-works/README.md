# Dusk Raven Works

**Studio concept status:** Preferred direction in development. **Not yet a launched publisher or cleared commercial mark.**

Dusk Raven Works combines an emotionally evocative violet-night identity with the productive meaning of *Works*. The signature scene is a watchful raven perched on a branch before a monumental moon. The studio can create games and interactive works across genres; the visual identity should never imply a single genre restriction.

## Distinction from other concepts

The earlier [Duskheron seed](../seed-ledger.md) inspired the atmosphere, but it remains a separate preserved seed. **Dusk Raven Works is not a rename of Duskheron or Onyx Foundry**. [Onyx Foundry](../onyx-foundry/README.md) retains its own separate identity and artwork.

## Publication limits

The first raven-and-moon PNG has been verified in the working conversation, and its identifying checksum and metadata are recorded in [the import manifest](brand/media-import.json). **The PNG binary is not yet stored in this GitHub repository.** Do not render a broken preview or describe the source as an editable vector file. There is no published game, account, or storefront for this studio yet.
