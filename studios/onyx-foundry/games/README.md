# Onyx Foundry — game catalog

Ideas for games that might be created or published under Onyx Foundry belong here. **No particular title is committed to production yet.** Many genres are welcome; the constant is strong systems and emotional seriousness, not a single genre.

For each actual idea, create `<slug>/README.md` from the [game concept template](../../../templates/game-concept.md). Different ideas can coexist, contradict each other, or remain dormant without forcing a ranking.

Useful fields: player fantasy, emotional intent, systems thesis, core loop, genre/platform, references, feasibility, potential studio identity variant, status, and separate code repo if eventually created.

For broad formats before there is a game idea, use [cross-studio game-type exploration](../../../explorations/game-types.md).
