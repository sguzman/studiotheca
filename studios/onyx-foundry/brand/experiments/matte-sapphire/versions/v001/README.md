# v001 — proposed seven-color matte palette

**Status:** Working numeric specification; the color family is accepted, but hex values are not exact samples of the art.

| Token | Hex | Material/function |
| --- | --- | --- |
| Obsidian Black | `#101113` | Matte dark foundation |
| Foundry Charcoal | `#292A2B` | Secondary darks |
| Forged Iron | `#777774` | Hardware |
| Pale Stone | `#D5CEC3` | Flat matte serif wordmark |
| Carved Walnut | `#80563A` | Wooden macuahuitl/F stem |
| Sapphire Blue | `#24539B` | Small crystals/gem accents |
| Onyx Vein | `#AAA49A` | Stone texture accent |

**Finish constraints:** matte dominant; gemstone glow only where it has physical cause and appropriate local light spill. Animated variants may have brighter brief pulses, but persistent neon rims are not the baseline.
