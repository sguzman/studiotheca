# Studiotheca Agent Rules

Read [CONSTITUTION.md](CONSTITUTION.md). Default to direct commits on `main` when authorized.

- Maintain the established creative archive; do not invent game releases, studios, approvals, or artwork.
- Keep nonpublic conversation fragments, venting, personal internal notes, secrets, and unpublished private data out of all public surfaces.
- Use neutral, independently written archival and design language.
- Preserve original files and numbered experiment versions; never claim absent source imagery was imported.
- Inspect origin, licensing, and provenance before publishing images, fonts, audio, or other assets.
- Update the ontology and gallery indexes whenever their documented subjects or published assets change.
- Keep game implementations in separate repositories; do not register this project elsewhere without explicit approval.
- Run `python3 scripts/validate.py` and independently review the resulting publication for material automated checks cannot detect.
