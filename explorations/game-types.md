# Types of games — exploration catalog

This is a **sandbox, not a production roadmap**. The studio need not be genre-bound, and none of these categories is an announced game.

| Family | Possible systems question | Possible emotional direction |
| --- | --- | --- |
| Role-playing / narrative simulation | Can relationships, consequences, and character growth emerge from rules? | Responsibility, regret, attachment |
| Strategy / political / economic simulation | How do institutions and incentives interact? | Ambition, compromise, collapse |
| Management / construction | Can material constraints drive meaningful decisions? | Stewardship, control, loss |
| Action / combat | Can movement, timing, equipment, and mastery create depth? | Resolve, tension, exhilaration |
| Exploration / atmospheric science fiction | Can environments tell a story through interaction rather than exposition? | Isolation, awe, melancholy |
| Sandbox / systemic experimentation | Can a few reliable primitives generate unanticipated play? | Curiosity, agency, surprise |
| Short-form experimental game | Can one mechanical or emotional thesis carry the experience? | Focused intensity |

**Selection question:** What *specific game* would be worth making in each family? A category only becomes a game when it has a distinct premise and systems thesis. Link such ideas into a studio's `games/` collection.

This is a brainstorming scaffold, not a list of the user's decided titles.
